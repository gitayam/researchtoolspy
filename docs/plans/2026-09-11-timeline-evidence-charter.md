Outcome: an analyst can attach inspectable source assertions and quote/locator snapshots to events, separate supports/contradicts/context, record known derivation, and explicitly review independence/compatibility before new corroboration labels. All evidence survives local export/import and existing human/service immutable workspace saves. No new database, migration, source fetching, credentials, or cross-product changes. Existing mutable/expiring source tables are not claimed as pinned evidence by caller-supplied IDs.

Wire contract: optional analystWorkspace.evidence is {schemaVersion:'timeline-evidence.v1',sources,assertions,links,reviews}. Sources (max100): {id,url,title,publisher,publishedAt?,retrievedAt?}; title nonblank<=1000, publisher<=1000, URL credential-free HTTP(S)<=4096, clocks ISO timestamps. Assertions (max200): {id,sourceId,claimText,temporalClaim,passage:{id,quote,locator},status:'active'|'retracted',derivesFrom:string[],observedAt?,reportedAt?}; claim nonblank<=4000, temporalClaim<=1000, quote<=4000, locator nonblank<=1000, unique passage IDs, derivation max20 valid IDs with no self/cycles. Links(max400): {id,eventId,assertionId,relation:'supports'|'contradicts'|'context'}; unique IDs and event/assertion pair. Reviews(max100,one/event): {eventId,independence:'independent'|'dependent'|'unresolved',compatibility:'compatible'|'incompatible'|'unresolved',rationale,reviewedAt,basis}; rationale nonblank<=4000, reviewedAt ISO, basis<=262144 canonical text. All IDs existing strict stable grammar<=200; unknown fields, duplicates, dangling references and malformed dates/URLs fail closed. Legacy evidence absence remains absent, not rewritten into old saved hashes. Existing4MiB local and60KiB durable/64KiB request bounds remain unchanged.

Shared helpers: emptyTimelineEvidence(); validateTimelineEvidence(value,eventIds) throws; timelineEvidenceBasis(evidence,event) returns deterministic canonical JSON covering event claim/date fields, all linked assertions including transitive derivation and their source/passage content, sorted by IDs; timelineCorroboration(evidence,event) returns {eligible,reason}; timelineAssessmentLabel(evidence,event) returns truthful display label. Corroboration requires at least2 active support assertions with disjoint derivation-root source URLs (normalized URL without fragment), no active contradiction, and current exact-basis independent+compatible review with rationale. Same-source/derivative/circular reports never satisfy the gate by count alone. Basis excludes assessment/narrative/display fields, includes all event links and relevant claim content so edits invalidate review. Legacy/raw imported corroborated labels without eligible review remain readable but display 'Corroboration needs review'; they are never presented as verified. Do not auto-create provenance from model summaries. Review is analyst-entered, not verified external provenance or peer certification.
