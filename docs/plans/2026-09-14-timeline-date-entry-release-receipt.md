# Recorded-date entry

The [timeline Analyst view](https://researchtools.net/dashboard/tools/timeline) now offers a collapsed **Date picker** when adding or editing an event. Native day/month inputs and a bounded year field supplement the existing typed **Date** input. Explicit precision text distinguishes year, month, day, absent and invalid recorded dates; no current date or missing components are filled automatically.

Changing picker mode or entering an incomplete value leaves the recorded draft intact. A valid picker value replaces only the draft date, and **Save event** applies it through existing validation. Cancel leaves the event unchanged. **Clear recorded date** clears only the date and preserves the clock with guidance when the day is unknown. No API, schema, save-format or extraction behavior changes. **TL-06 remains in progress**, now including timing diagnostics and precision-preserving date entry; structured intervals, circa dates, clock mappings and extraction v2 remain pending. TL-17 remains partial and TL-13 planning is not delivered.
