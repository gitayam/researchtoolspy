# Direct presentation links

Choose **Share presentation → Publish presentation → Copy link** to create a frozen, read-only presentation at `/present/:token`. Recipients can open it without login and use the slides or searchable event list. Creators can revoke links through **Manage links**. Opening a preview does not publish it. Publication includes visible framing, assessments and schedule assumptions; workspace evidence, raw source and the complete backup remain private.
