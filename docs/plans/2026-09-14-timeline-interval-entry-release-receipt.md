# Local recorded interval authoring

In [Analyst Add/Edit event](https://researchtools.net/dashboard/tools/timeline), **Record an end date** adds an optional inclusive end date and clock alongside the existing start. Fields start empty, preserve year/month/day precision and reject missing, malformed or definitely reversed endpoints before changing the event. Cancel preserves the event; switching the end off removes it only on Save. Original extraction remains separate.

Recorded intervals round-trip in local browser drafts and complete JSON backups using workspace/draft v2. Interval-free exports stay v1. Inclusive endpoint units and overlapping precision retain uncertainty rather than inventing a duration. This is a local schema change, with no server storage schema, API, migration or discovery change.

Private workspace saving is unavailable for intervals and fails before requests; existing v1 history remains readable. TimelineJS explicitly omits intervals even with presentation scheduling, while other eligible events can export and the complete backup retains all interval data. **TL-06 remains in progress**: durable v2 and renderer endpoint support are next, then circa dates, clocks and extraction v2.
