Judgment fields (all required): id; claim(nonblank4000); scope(nonblank1000); asOf(ISO timestamp); reasoning(nonblank4000); likelihood:{vocabulary:'timeline-verbal.v1',value:'unassessed'|'unlikely'|'roughly_even'|'likely'}; analyticConfidence:'unassessed'|'low'|'medium'|'high'; confidenceBasis(nonblank4000); assumptions/alternatives/changeIndicators(each arrays max10 nonblank1000 strings); eventRefs/evidenceRefs/contraryEvidenceRefs(each max20 distinct existing IDs; evidence IDs reference assertions; support/contrary disjoint); status:'active'|'withdrawn'; changeReason(nonblank4000); updatedAt(ISO timestamp); basis(canonical JSON text max262144). At least one event or assertion reference required. Likelihood words are an explicit local qualitative vocabulary, not numeric probabilities or an institutional calibration. Confidence is never calculated from counts.

Review fields (all required): id; judgmentId(existing judgment); reviewerLabel(nonblank200, explicitly self-attributed, not verified identity/sign-off); position:'agree'|'challenge'|'dissent'; rationale(nonblank4000); alternative(text4000); createdAt(ISO timestamp); basis(canonical JSON text max262144 capturing complete reviewed judgment). Reviews append independently and cannot be edited/deleted by this UI. Withdraw/restore judgment instead of deleting it, retaining reviews; immutable prior durable revisions remain authoritative history. API snapshots validate shapes and preserve records, but do not claim append-only permissions across arbitrary authorized replacement snapshots or authenticated reviewer attestation.

Helpers in src/lib/timeline-judgments.ts: emptyTimelineJudgments(); validateTimelineJudgments(value,events,evidence?) asserts value; timelineJudgmentBasis(judgment,events,evidence?) canonical JSON covering selected event claim/date/placement fields and all referenced assertions with transitive ancestors/passages/clocks/source metadata, including event-linked assertions; timelineJudgmentNeedsReview(judgment,events,evidence?) boolean compares basis; timelineJudgmentReviewBasis(judgment) canonical JSON of complete judgment. Every canonical basis is strict parseable canonical JSON; stale bases remain valid/inspectable. Event basis reuse may call timelineEvidenceBasis. References are sorted for deterministic bases; presentation fields do not invalidate inputs. Source edits/retractions/event wording/reference changes invalidate judgment input basis. No strength/assessment promotion follows automatically.
