# Stored Content Research passage import charter

Outcome: signed-in analysts can import a matching passage from their own complete stored Content Research extraction into an opened private Timeline workspace. The quote remains separate from analyst wording. This is a partial TL-04 user-visible release at `/dashboard/tools/timeline`, not certification of source truth or immutable external provenance.

Baseline: `a2d364bb8b80a56dbc281b244b967cf572b702e9`, freshly equal canonical `origin/main` and mirror `gitlab/main`. Shared clean integration: `/Users/sac/AgentWorkspaces/researchtoolspy-timeline-foundation-20260911`; primary checkout remains untouched. Existing project policy and CLAUDE instructions apply. User authorized clean non-force pushes to both main refs and production deployment after acceptance. No DB migration, credential change, source fetch, model call or cross-product release.

Storage authority: only `content_analysis.extracted_text` on an explicitly selected numeric ID, owned by the current active non-guest human, in the exact selected private workspace with current write access. Reject missing/expired/unfinished content, missing or mismatched SHA-256, text over 102400 UTF-16 units, the writer's truncation marker, and unsafe URL metadata. Do not reconstruct non-atomic content chunks or use editable Evidence Library descriptions. `created_at` is not a retrieval clock; do not turn it into one.

Protocol: new read-only POST `/api/timeline-source-import`, no database writes, standard Timeline error envelope/no-store response/CORS. Body, strictly validated and bounded by existing 64 KiB reader: `{schemaVersion:'timeline-source-import-request.v1', workspaceId:string, analysisId:positive safe integer, quote:nonblank string <=4000 UTF-16 units, expectedContentHash?:lowercase SHA256}`. No unknown properties; reject malformed Unicode. Require exact, unique occurrence of quote in complete text (overlapping occurrences count). Offsets are UTF-16 `[start,end)`. Recompute UTF-8 SHA256 for text and quote. Optional expected hash must match the current complete text or return stale_revision/412. Missing/inaccessible source returns not_found/404 without metadata. Invalid/unusable content returns invalid_request/400; bounds return limit_exceeded/413. Accept retained records only with `is_saved=1` and null expiry; unsaved records need a parseable strictly future expiry. Reject inconsistent retained-expiry states. Require existing human authentication, never guest provisioning; service identities cannot use this human-only source store. One final SELECT checks active-user/private-workspace/write-membership and record ownership together after human authentication; denial is uniformly not_found/404, including revoked workspace access.

Response type `TimelineSourceImport` in `src/types/timeline-source-import.ts`: `{schemaVersion:'timeline-source-import.v1',workspaceId,analysisId,contentHash,quoteHash,start,end,matchedAt,source:TimelineEvidenceSource,passage:{id,quote,locator}}`. Source ID `content:<analysisId>:<contentHash>`; passage ID `passage:<analysisId>:<contentHash>:<start>:<end>`. Title uses stored title (or URL hostname), publisher URL hostname; preserve URL only if valid HTTP(S) without credentials. Omit uncertain publication/retrieval clocks. Locator records analysis ID, content hash, UTF-16 range, quote hash and match time plus an explicit recorded-reference qualification, within 1000 units. Response fits current evidence bounds. Existing evidence schema is unchanged: hash/range are recorded in the locator, and downloaded/imported JSON is never promoted to an authenticated receipt.

Consumer: only an opened saved private Timeline exposes import controls; parent passes `sourceImportWorkspaceId` when the opened workspace is writable. Local/guest timelines show guidance to save then reopen. Existing remote-content memory-only behavior applies; no private passage is written to browser draft storage. Workspace/identity changes clear the opened content and abort or discard pending import responses. Analyst supplies record ID and exact quote, previews a match, supplies separate claim text and relation, then explicitly imports. Before applying, re-resolve with expected content hash. Changing ID/quote invalidates preview. Source state and evidence limits are checked at application time; never overwrite a conflicting deterministic source ID. Reuse identical existing source/passage where valid, never duplicate passage IDs or silently overwrite an assertion. No import sets corroboration, independence or confidence.
